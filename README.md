# HiPass for Windows

HiPass의 Windows 설치파일과 앱 업데이트를 제공하는 공식 배포 저장소입니다.

- [공식 다운로드](https://hipass.despitethat.com/download/)
- [공식 사이트](https://hipass.despitethat.com/)
- [사용 안내](https://hipass.despitethat.com/guide/)
- [릴리스 목록](https://github.com/tkim-au/HiPass-Releases/releases)

현재 정식 버전은 **0.1.5 · Windows 11 x64**입니다. [공식 다운로드](https://hipass.despitethat.com/download/) 또는 [0.1.5 릴리스](https://github.com/tkim-au/HiPass-Releases/releases/tag/v0.1.5)에서 `HiPass-0.1.5-Setup.exe`를 내려받으세요. Python과 앱 실행에 필요한 구성 요소가 설치파일에 포함됩니다.

기존 화면 구성을 유지하고 설명과 버튼 문구를 줄였습니다. 자동 보내기·받기를 기본으로 표시하며 수동 전송은 설정의 **수동 모드 사용**에서 켤 수 있습니다. 앱 정보에서 업데이트를 확인할 수 있습니다.

업데이트는 앱을 사용하는 동안 준비하고, 내용이 같은 파일은 재사용해 종료 후 대기를 줄입니다. **새 방식은 0.1.5에서 시작하는 다음 업데이트부터 적용됩니다.** 0.1.4 이하에서 이번 버전을 설치할 때는 기존 방식이 사용되어 시간이 걸릴 수 있습니다. 다운로드는 전체 패키지를 사용합니다.

**Windows 코드 서명이 없는 설치파일입니다.** 설치·실행 시 ‘알 수 없는 게시자’ 또는 Microsoft Defender SmartScreen 경고가 나타날 수 있으며, PC 보안 정책에 따라 실행이 차단될 수 있습니다.

앱의 업데이트 목록 서명과 패키지 해시 검증은 유지됩니다. 이전 0.1.0 내부 시험본은 업데이트 주소가 없으므로 이번 설치파일을 한 번 수동 설치해야 합니다.

`Source code` 압축파일과 `.nupkg`는 Windows 설치파일이 아닙니다. `.nupkg`와 `update-index.json`은 앱 내부 업데이트에 사용됩니다.

릴리스에 함께 제공되는 `SHA256SUMS.txt`로 내려받은 파일의 SHA-256을 확인할 수 있습니다.
