# HiPass for Windows

HiPass의 Windows 설치파일과 앱 업데이트를 배포하는 공식 공개 저장소입니다.

- [공식 다운로드](https://hipass.despitethat.com/download/)
- [사용 안내](https://hipass.despitethat.com/guide/)
- [릴리스 목록](https://github.com/tkim-au/HiPass-Releases/releases)

현재 정식 버전은 **0.1.9 · Windows 11 x64**입니다. [0.1.9 릴리스](https://github.com/tkim-au/HiPass-Releases/releases/tag/v0.1.9)에서 `HiPass-0.1.9-Setup.exe`를 내려받거나 앱에서 업데이트를 확인하세요.

데스크톱의 수동·자동 보내기 화면에서 **일반 / JSON / 자동**을 선택할 수 있습니다. 기본값은 자동이며 두 화면의 마지막 선택을 각각 기억합니다.

| 방식 | 파일 준비 |
|---|---|
| 일반 | HiPass가 직접 읽어 기존 경로로 전송합니다. |
| JSON | 선택한 모든 파일을 발신 PC에 설치된 별도 Python 3으로 읽어 JSON으로 준비합니다. |
| 자동 | 직접 읽은 뒤 NASCA 헤더가 관측된 PPTX·XLSX만 별도 Python 읽기를 시도합니다. |

일반 전송과 수신에 필요한 실행 환경은 설치파일에 포함됩니다. **JSON 방식과 자동 방식의 Python 재시도는 발신 PC에 별도 Python 3이 필요합니다.** 사용자가 JSON 파일을 직접 옮길 필요는 없습니다. 웹 업로드에는 이 선택 옵션이 없습니다.

전송은 읽힌 전체 파일 바이트를 유지하고 수신 파일의 크기·SHA-256을 검증합니다. 상세 읽기 경로와 해시는 접힌 **검증 정보**에서 볼 수 있습니다. 헤더가 보이지 않는다는 이유로 DRM이 없다고 판정하지 않으며, 모든 DRM 환경에서 읽기를 보장하지 않습니다. Python 읽기 실패나 Python으로 읽은 결과에 NASCA 데이터가 남으면 오류로 표시합니다. 방식을 비교할 때는 같은 원본으로 새 전송을 시작하세요. 이어하기는 최초 준비 결과를 유지합니다.

**두 PC 자동 키 연결**을 지원합니다. 양쪽 PC를 업데이트하고 같은 Overleaf 계정 또는 공유 프로젝트를 연결하세요. **설정 → 암호화 설정**에서 한 PC는 **연결 시작**, 다른 PC는 **연결 참여**를 선택합니다. 두 화면의 네 묶음 확인 코드 전체를 직접 비교하고, 모두 같을 때만 양쪽에서 **확인 코드가 같습니다**를 누르세요. 다르면 취소합니다. 연결 뒤 공유 비밀키는 각 PC에 안전하게 저장되고 전송 암호화가 켜집니다.

암호화는 파일명과 내용을 PC에서 암호화한 뒤 Overleaf에 전달하며 자동전송의 재전송·이어받기도 지원합니다. 공유 비밀키는 Overleaf에 올리지 않습니다. 전송 시간·크기·프로젝트 정보나 받는 PC에 저장한 최종 파일까지 숨기는 기능은 아닙니다. [자동 연결과 암호화 안내](https://hipass.despitethat.com/guide/#종단간-암호화)

자동 보내기·받기를 기본으로 표시하며 수동 전송은 설정의 **수동 모드 사용**에서 켤 수 있습니다. 앱 정보에서 업데이트를 확인할 수 있습니다. 초기 0.1.0 설치본은 업데이트 주소가 없어 새 설치파일로 한 번 직접 설치해야 합니다.

**Windows 코드 서명은 없는 설치파일입니다.** 업데이트 목록의 Ed25519 서명과 패키지 해시 검증은 적용됩니다. 릴리스의 `SHA256SUMS.txt`로 다운로드한 파일의 SHA-256을 확인할 수 있습니다. `Source code` 압축파일과 `.nupkg`는 설치파일이 아닙니다. `.nupkg`와 `update-index.json`은 앱 내 업데이트용입니다.

실제 두 PC에서의 전송과 외부 문서 열람은 해당 환경에서 확인해야 합니다.
